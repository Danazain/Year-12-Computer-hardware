💻 The Computer Upgrade Challenge

A computer has 4 GB of RAM and a hard disk drive (HDD). It takes a long time to start and slows down when several applications are open.

You can either add more RAM or replace the HDD with an SSD.

Which upgrade would you choose first, and why?

Discuss with your partner. Where appropriate, use the terms volatile, non-volatile, access time and storage.

Suggested explanation

Both upgrades can help, but in different ways. Adding RAM can improve multitasking when available memory is insufficient. Replacing an HDD with an SSD generally improves startup and application loading times. The best first upgrade depends on which bottleneck is causing the slowdown.
